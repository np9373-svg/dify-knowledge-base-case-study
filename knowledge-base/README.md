# База знаний

В каталоге [`parents`](parents) находятся 15 финальных документов для загрузки в Dify.

Каждый файл является одним parent-документом. Смысловые разделы внутри файлов разделены строкой:

```text
@@CHILD@@
```

При загрузке нужно выбрать Parent-Child chunking и указать эту строку как явный разделитель child-чанков.

Принципы разбиения и критерии границ описаны в [документе об архитектуре](../docs/knowledge-architecture.md). Точные retrieval-настройки приведены в [инструкции по импорту](../dify/import-and-run.md).
