# Dify бесплатно: Cloud Sandbox и Community Edition

Dify можно использовать бесплатно двумя разными способами. Cloud Sandbox предоставляет готовую облачную среду с квотами. Community Edition устанавливается самостоятельно и бесплатно даёт одно workspace и основные функции из публичного репозитория.

Выбор зависит от того, нужна ли готовая облачная среда с заданными ограничениями или собственная установка через Docker.

## Dify Cloud Sandbox

Sandbox позволяет начать работу в Dify Cloud без самостоятельного развёртывания. Тариф предоставляет 200 пробных message credits. Каждый ответ модели расходует кредиты. В отличие от платных тарифов Professional и Team, для Sandbox на странице тарифа не указано ежемесячное обновление этих кредитов. После их исчерпания можно подключить собственный API-ключ провайдера.

Кроме кредитов, действуют ограничения на ресурсы:

- одно workspace;
- один участник;
- пять приложений;
- 50 документов базы знаний;
- 50 MB хранилища;
- хранение истории логов в течение 30 дней.

## Квота запусков Cloud Sandbox

В Sandbox доступно 5 000 запусков приложений и workflows в месяц. На странице тарифов эта квота названа API Rate Limit.

Она расходуется в следующих случаях:

- внешний вызов опубликованного приложения через Service API;
- запуск из опубликованного web app;
- запуск из отладчика приложения;
- запуск через OpenAPI;
- асинхронный запуск workflow по триггеру.

Это не общий лимит на любые endpoint’ы Dify. Для операций с базами знаний установлен отдельный лимит.

@@CHILD@@

## Лимит операций с базой знаний Cloud Sandbox

Для Sandbox действует ограничение 10 запросов в минуту на операции с базами знаний. В него входят создание, удаление и обновление баз, загрузка, изменение и архивирование документов, а также запросы к базам знаний.

При оценке Sandbox важно учитывать обе квоты отдельно: месячные запуски приложений и workflows не заменяют поминутный лимит Knowledge API.

@@CHILD@@

## Dify Community Edition

Community Edition бесплатно предоставляет одно workspace и основные функции Dify, опубликованные в публичном репозитории. Dify работает везде, где доступен Docker: на ноутбуке, локальном сервере или cloud VM.
