# Реестр фактов

`facts.xlsx` — рабочий реестр атомарных фактов, из которых собиралась база знаний.

Основная таблица содержит:

- `fact_id` — стабильный идентификатор;
- `fact` — исходная формулировка;
- `translation` — перевод;
- `fact_base` — отредактированная формулировка для базы;
- `source` — официальный источник;
- `question_id` — связь с исходными вопросами.

Реестр не загружается в Dify напрямую. Он служит слоем проверяемого сырья между документацией и финальными статьями.
